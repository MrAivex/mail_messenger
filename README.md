# Почтовый мессенджер (MailMess)

Клиент-клиентный мессенджер, работающий через обычную электронную почту (POP3/SMTP). Сообщения отправляются как письма и проходят фильтрацию по специальным заголовкам.

## Описание

Приложение позволяет обмениваться сообщениями между пользователями, используя почтовые ящики в качестве транспортного слоя. Для работы требуется **почта на Mail.ru** (тестировалось с паролями приложений).

**Как это работает:**
- Исходящие сообщения отправляются через SMTP (smtp.mail.ru:465)
- Входящие проверяются по POP3 (pop.mail.ru:995)
- Письма-сообщения маркируются специальными заголовками (`X-MailMess: 1`) для фильтрации обычной почты
- Каждое сообщение имеет уникальный ID (Message-ID) для предотвращения дублирования
- База данных SQLite хранит сообщения, контакты и историю

## Возможности

- 🔐 **Вход** с автозаполнением сохранённых учётных данных
- 💬 **Чат** с произвольным количеством контактов
- 📋 **Список контактов** — автоматическое добавление при получении сообщения или ручное через кнопку
- 🕒 **Адаптивный интервал проверки почты** — при ошибках интервал увеличивается (до 60 секунд)
- 📨 **Поддержка multipart писем** и MIME-декодирование (base64, quoted-printable, RFC 2047)
- 🌙 **Тёмная тема** оформления
- 🗃️ **Локальное хранение** всех сообщений (SQLite)
- ⚡ **Асинхронная работа** — POP3 работает в отдельном потоке, не блокируя интерфейс

## Сборка и запуск

### Требования

- Qt 5.15 или новее (с модулями `core`, `gui`, `widgets`, `sql`, `network`)
- Компилятор с поддержкой C++17
- Учётная запись на **Mail.ru** (другие почтовые сервисы не тестировались, но могут работать при смене POP3/SMTP серверов)

### Инструкция

```bash
# Клонирование репозитория
git clone <repository-url>
cd MailMessenger

# Сборка с помощью qmake
qmake MailMess.pro
make

# Запуск
./MailMessenger
```

### Настройка почтового ящика (Mail.ru)

Для работы необходимо создать **пароль приложения**:

1. Войдите в настройки безопасности Mail.ru
2. Раздел «Пароли приложений» → «Создать пароль приложения»
3. Выберите тип «Почта» (или любой другой, но дайте ему доступ к почте)
4. Скопируйте полученный пароль — он будет использоваться для входа в приложение

Обычный почтовый пароль не подойдёт из-за требований двухфакторной аутентификации на Mail.ru.

### Ключевые классы

| Класс | Назначение |
|-------|------------|
| `MainWindow` | Управляет переключением между окнами входа и чата |
| `LoginWidget` | Интерфейс ввода email и пароля |
| `ChatWidget` | Основной интерфейс чата (список контактов, область сообщений) |
| `MessageStore` | Хранилище в SQLite + кэш контактов и сообщений в памяти |
| `SmtpClient` | Отправка писем через SMTP с TLS |
| `MailChecker` | Обёртка для Pop3Client, запускает его в отдельном потоке |
| `Pop3Client` | Проверка почты, фильтрация только наших писем (POP3) |
| `MimeParser` | Парсинг MIME-писем и извлечение текста |

## Формат сообщений

Отправляемое письмо:

```
From: user1@mail.ru
To: user2@mail.ru
Subject: [MailMess] chat
Message-ID: <uuid@mailmess.local>
X-MailMess: 1
MIME-Version: 1.0
Content-Type: text/plain; charset=utf-8
Content-Transfer-Encoding: 8bit

Текст сообщения
```

При получении фильтруются только письма, содержащие:
- Заголовок `X-MailMess: 1` **или**
- Заголовок `Subject: [MailMess]`

Обычные письма игнорируются.

## Управление

- ➕ **Добавить контакт** — по email (ручное добавление)
- 🚪 **Выйти** — закрывает сессию и возвращает на экран входа
- 💬 Начать чат можно:
  - Кликнув на контакт в левой панели
  - Введя email в поле «Кому» и нажав «Начать чат»

## База данных

Файл `messenger.db` создаётся в:
- Linux/macOS: `~/.local/share/MailMessenger/`
- Windows: `%APPDATA%/MailMessenger/`

Таблицы:
- `auth` — сохранённые учётные данные
- `messages` — все сообщения (msg_id, sender, receiver, body, timestamp, incoming)
- `contacts` — список контактов
- `seen_uids` — UID уже обработанных писем (для избежания дублей при повторной проверке)

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Ошибка аутентификации | Используйте **пароль приложения**, а не обычный пароль от почты |
| Не приходят сообщения | Проверьте, что оба пользователя используют одно приложение (заголовок `X-MailMess`) |
| Сообщения дублируются | MessageStore проверяет уникальность `messageId` перед добавлением |
| Долгая проверка почты | При ошибках интервал увеличивается (адаптивная задержка), но после успеха сбрасывается |
| Не распознаются письма | Убедитесь, что письмо имеет тему `[MailMess]` или заголовок `X-MailMess: 1` |
